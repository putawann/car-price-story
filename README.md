# เรื่องเล่าราคารถยนต์มือสอง

เว็บเล่าเรื่องแบบ static จากงานวิจัยการประเมินราคารถยนต์มือสอง
สร้างด้วย HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งหรือ build

## เปิดใช้งาน

ดับเบิลคลิก `index.html` ได้เลย (รองรับ `file://`) หรือเปิดผ่านเบราว์เซอร์สมัยใหม่
ต้องต่ออินเทอร์เน็ตเฉพาะการโหลดฟอนต์ Prompt จาก Google Fonts

## คีย์ลัด

| ปุ่ม | การทำงาน |
|---|---|
| `Space` | เล่น / หยุด |
| `→` หรือ `PageDown` | ฉากถัดไป |
| `←` หรือ `PageUp` | ฉากก่อนหน้า |
| `Home` / `End` | ฉากแรก / ฉากสุดท้าย |

กดปุ่ม ▶ ด้านล่างเพื่อเล่นอัตโนมัติ คลิกแถบความคืบหน้าเพื่อข้ามฉาก
และกด “↻ เล่นแอนิเมชันอีกครั้ง” ในแต่ละฉากเพื่อดูแอนิเมชันซ้ำ
